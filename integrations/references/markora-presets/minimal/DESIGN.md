# Minimal

## Purpose
Work, services and small product pages. Quiet, direct.

## Color roles
Foreground #202b28; background #fafbf9; accent #356752. Verify contrast for each actual combination. Use accent sparingly; add a text label to status colors.

## Typography
System sans-serif; 56/36/24/16 px. Body line height 1.65; headings 1.08. Paragraph measure 65ch. Use local fonts unless the project already supplies another family.

## Layout
An aligned masthead, a text-led opening, project rows and a compact contact footer. Use thin rules instead of repeated cards.

## Spacing and controls
Spacing scale: 4, 8, 12, 16, 24, 40, 64 px. Content width up to 1160 px, with 24 px minimum side padding. Make primary controls at least 44 px high. Include hover, focus, active, disabled, loading and error states where relevant.

## Responsive behavior
At 720 px, stack major columns and reduce display type with clamp(). Keep navigation and all actions reachable. Check long titles, multilingual text and overflow.

## Motion and copy
Use opacity or transform transitions of 160-240 ms for meaningful feedback. Reduced motion renders content immediately. Preserve actual facts and links; omit empty sections. Write clear sentences without hype or invented statistics.
