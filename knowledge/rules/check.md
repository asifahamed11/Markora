# Evidence and review

Separate syntax checks, rendered measurements, interaction tests and subjective visual review. Report their actual scope and source revision. Accessibility automation leaves incomplete/manual checks. Heuristic design warnings are not proof that a design is poor or inaccessible.

Automatic refinement must preserve supplied claims, names, links and working interactions. Fix real rendering failures first, then the highest-impact composition issue. Bound repairs and timeouts. Compare a rendered result against the selected direction, not against an arbitrary numeric beauty score.
