# Precise edits

Resolve the selected source revision and text range before writing. Never expand a letter mark to its whole heading. Keep grapheme clusters intact. Dynamic text and repeated component instances need explicit source scope; ambiguity is a reason to stop, not guess.

Colour and size commands about one control use a local override. Shared token changes require an explicit theme-wide request. Preserve the selected JSX root, handlers, surrounding text and siblings. Publish one checked history revision, then report exactly what changed.
